# Murekefu Music Hub User Manual

## 1. Purpose

This manual helps users understand how to navigate Murekefu Music Hub and complete the most common actions in the system.

The platform supports:

- visitors
- learners
- buyers
- composers
- administrators

## 2. Main Navigation and Menus

The top navigation now uses grouped menus so users can find pages faster without
having too many items in one row.

### Home Menu

Use the `Home` menu for public platform information:

- Home
- About Us
- Testimonials
- Help
- Contact Us

### Services Menu

Use the `Services` menu for the main platform entry points:

- Learn Music
- Music Hub

### Dashboards Menu

When a user is signed in, role-based workspaces are grouped under
`Dashboards`. The system only shows the dashboards that match the current user.

Possible dashboard links include:

- Learner Dashboard
- My Library
- My Arrangements
- My Compositions
- Admin Panel

### Profile Menu

Use the profile or avatar menu for personal account actions:

- Manage Account
- appearance and profile settings
- sign out

### Landing Page

Use the landing page to:

- learn what the platform offers
- use the `Home` menu for platform information
- use the `Services` menu to enter Learn Music or Music Hub
- open Help and Manuals

### Music Hub

Use the marketplace to:

- browse arrangements and compositions
- search and filter listings
- switch between list and card layouts
- sort results
- preview a composition before purchase
- go directly to checkout

### My Library

Use the buyer library to:

- view approved purchases
- switch between list and grid view
- sort recent items
- search your purchased music
- download approved files

### My Arrangements and My Compositions

Use the composer area to:

- upload new work
- edit listing details
- review listing performance
- switch views depending on your device
- delete compositions or arrangements when necessary

### Manage Account

Use Manage Account to:

- open it from the profile or avatar menu
- update your profile
- take a selfie or upload a profile photo
- request roles
- change theme and layout settings
- personalize icon size, density, and surface style

### Messenger

Use Messenger to:

- talk to support
- open the community lounge
- send messages and attachments
- continue conversations in one place

### Admin Panel

Use the admin panel to:

- manage users and roles
- review requests and enrollments
- moderate compositions
- export PDF reports
- handle support and operational activity

## 3. Common User Actions

### Buy a Composition

1. Open `Services`, then select `Music Hub`.
2. Search or filter the listings.
3. Tap a composition to open the preview panel.
4. Review the details and play the MIDI sample if available.
5. Select `Purchase & Checkout`.
6. Complete the checkout process.
7. Return to `My Library` after approval to download the file.

### Upload a Composition or Arrangement

1. Open `Dashboards`.
2. Choose `My Arrangements` or `My Compositions`.
3. Select `Upload New`.
4. Fill in the title, description, pricing, and file details.
5. Save or publish the work.
6. Return to your listing area to monitor views, sales, and status.

### Change System Appearance

1. Open the profile or avatar menu.
2. Select `Manage Account`.
3. Go to `Appearance`.
4. Choose:
   - theme preset
   - light or dark mode
   - view size
   - icon size
   - layout density
   - surface style
5. The platform saves your preferences automatically.

### Start a Support Conversation

1. Open `Messenger` from the top navigation.
2. Choose the `Support` workspace.
3. Start a new conversation or continue an existing one.
4. Send your message and wait for response updates.

### Join the Community

1. Open `Messenger` from the top navigation.
2. Switch to `Community`.
3. Read messages, send your own, and join the public conversation.

## 4. Role Guidance

### Learners

- focus on enrollment, learning, and community support
- use the learner dashboard as your main workspace

### Buyers

- use Music Hub and My Library most often
- rely on preview, checkout, and library download flow

### Composers

- keep arrangements and compositions in their separate areas
- use listing tools to manage prices, publishing, and performance

### Admins

- use the admin panel for moderation, reporting, and support operations
- always review state-aware actions carefully before making changes

## 5. Help and Recovery

If a user gets stuck:

- open the in-app Help and Manuals page
- use Messenger support
- contact the Murekefu team through the contact page
